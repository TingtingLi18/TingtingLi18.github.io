# Tingting Li Academic Website V3

## Preview locally
Double-click `index.html` to open the website in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload the **contents** of this folder (not the outer folder itself).
3. Confirm `index.html` is in the repository root.
4. Go to Settings → Pages.
5. Choose “Deploy from a branch”, branch `main`, folder `/ (root)`.
6. Save and wait a few minutes for deployment.

## Main files
- `index.html` — homepage
- `research.html` — research program
- `projects.html` — funded projects
- `publications.html` — selected publications
- `team.html` — research community
- `teaching.html` — teaching
- `service.html` — service and recognition
- `assets/images/tingting-li-headshot.png` — headshot

## CV privacy
The CV is intentionally not included in this public website package. All “Request CV” links open an email request to tingting.li1@wsu.edu.
